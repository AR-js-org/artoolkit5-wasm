# License Header Adder

Applies the project's MIT license header to source files in `artoolkit5-wasm`.

The project lives in [AR-js-org](https://github.com/AR-js-org) and follows
[AR.js's licence](https://github.com/AR-js-org/AR.js/blob/master/LICENSE).

## Template

`resources/HEADER.txt`, with two substitutions:

- `{{FILENAME}}` — the target file's **basename** (`ARToolKitCore.cpp`, not
  `cpp/arjs/artoolkit5/ARToolKitCore.cpp`).
- `{{LINEAGE}}` — one of the three blocks below. **Choosing the right one is the
  point of this skill**: this package ships a WebAssembly binary compiled from
  LGPLv3 code, but not every file in the repository takes part in that.

Each block below already includes its blank ` *` lines above and below; paste it
over the `{{LINEAGE}}` line unchanged.

## Which lineage block

### A. Build tooling — no lineage block

`scripts/*.mjs`

These run Docker and clang-format. They never touch WebARKitLib. Replace
`{{LINEAGE}}` with a single blank comment line:

```
 *
```

### B. C++ — compiled into the binary

`cpp/**/*.cpp`, `cpp/**/*.h`

`ARToolKitCore` includes ARToolkit5 headers and is linked with WebARKitLib into
`dist/artoolkit5.wasm`.

```
 *
 *  This file is compiled together with ARToolkit5 (WebARKitLib), which is
 *  licensed under the GNU Lesser General Public License v3.0, into the
 *  WebAssembly binary distributed in this package.
 *
```

### C. TypeScript — the published wrapper

`src/*.ts` (including `src/*.d.ts`)

```
 *
 *  This library wraps a WebAssembly build of ARToolkit5 (WebARKitLib), which
 *  is licensed under the GNU Lesser General Public License v3.0.
 *
```

Keep that sentence exactly as written. The MIT licence covers this repository's
code, not the underlying engine, and downstream users need to know what they are
shipping.

## Applies to

- `.ts` and `.d.ts` files in `src/`
- `.cpp` and `.h` files in `cpp/`
- `.mjs` files in `scripts/`

## Rules

1. **Insert at the very top of the file**, followed by one blank line before the
   first line of code.
2. **Skip files that already have a header.** Detect by checking whether the
   first block comment contains `Copyright (c)`. Never stack a second one.
3. **Replace an IDE banner.** A leading `//` comment block generated by an IDE
   (CLion's `// Created by <user> on <date>.`) is not a licence header. Remove it
   and put the header in its place; credit lives on the `Author(s):` line.
4. **Do not modify** `node_modules/`, `dist/`, `build/`, `cmake-build-*/`,
   `third_party/`, `.agents/`, or any vendored code.
5. **Do not apply to** `.json`, `.md`, `.yml`, `.html`, or data files, nor to
   `examples/` (hand-written demos and a legacy `ARController.js`).
6. **Config files** (`vite.config.ts`, `tsconfig*.json`, `CMakeLists.txt`,
   `.clang-format`) are out of scope — no meaningful authorship.
7. **Year** is fixed at `2026` in the template. Do not bump it per file on edit;
   change the template and reapply repo-wide.
8. **Author line**: keep `Walter Perdan @kalwalt` unless a file has a different
   principal author, in which case add them rather than replacing.
9. **Match the file's line endings** (CRLF or LF) when inserting.

## After applying

- **TypeScript:** `tsc` runs without `removeComments`, so the header of
  `src/index.ts` and `src/loader.ts` is copied into `dist/index.d.ts` and
  `dist/loader.d.ts`. `dist/` is committed, so run `npm run build:wrap` and commit
  what it produces.
- **C++:** a header changes no behaviour, but it moves every line of the file, and
  the committed wasm is a `-g2` build whose DWARF records those line numbers. Do
  **not** run `npm run build:wasm` just for this: the wasm is not byte-reproducible
  across machines and the debug-flags configuration is easy to change by accident
  (see `AGENTS.md`). The committed wasm's line table is simply off by the header's
  length until the next real C++ change rebuilds it.
- **Scripts:** nothing to rebuild.
- Run `npm run lint:cpp` after touching `cpp/`.

## Copyright attribution

The copyright holder is **`AR-js-org`** — the organisation, not an individual.
Individual credit belongs on the `Author(s):` line. This matches
`artoolkit5-ts` and `artoolkit5-constants`.

Applying headers does **not** change `LICENSE`. At the time of writing `LICENSE`
in this repository still reads `Copyright (c) 2026 Walter Perdan`, while the
sibling repositories say `AR-js-org`. Aligning it is the owner's decision.

## Difference from the sibling repositories

- `artoolkit5-ts` uses the single block C everywhere. Here that is only correct
  for `src/`.
- `artoolkit5-constants` publishes numbers only and ships no binary, so it must
  **not** say its code wraps a WebAssembly build. This package does ship one, so
  block C is accurate here — do not copy constants' blocks, which understate it.
